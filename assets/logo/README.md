# The marks

Two of these files are used by the README; the rest are uploaded through GitHub's own settings
pages, which is why nothing in the repository references them.

| File | Where it goes |
|---|---|
| `vox2seglam-lockup.svg`, `-dark.svg` | the README heading, one per colour scheme |
| `social-preview.png` | Settings → General → Social preview (1280 × 640, what a shared link shows) |
| `avatar.png` | the organisation or account picture (512 × 512) |
| `icon-256.png` | a raster icon where an SVG will not do |
| `vox2seglam-icon.svg` | the mark alone, without the wordmark |
| `vox2seglam-logo.svg`, `-dark.svg` | the wordmark alone, without the mark |

The dark variants are the same drawing with the ink inverted, for a dark background. The SVGs
carry no external font: the lettering is outlined, so they render identically anywhere.
